FAQ

How do I connect my GitHub account?

Open the app, tap "Sign in with GitHub" and authorize via OAuth.

What is included in Pro Lifetime?

Unlimited repos, multiple GitHub accounts and unlimited Kanban columns. One-time purchase.

How do I restore my purchase on a new device?

Settings → Restore Purchases. Use the same Apple ID.

Where is my data stored?

Locally on device with optional iCloud sync via CloudKit. We never see your data.
