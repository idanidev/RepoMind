## 1. Integracion con flujo de desarrollo (Deep Links)

### Ya implementado en v1.4

URL Scheme `repomind://` con soporte para crear tareas:

```
repomind://add-task?content=Fix+login+bug&repo=my-app&column=To-Do
```

Parametros:
- `content` (requerido): texto de la tarea
- `repo` (opcional): nombre del repo destino. Si se omite, usa el mas reciente.
- `column` (opcional): nombre de la columna. Si se omite, usa la primera.

### Idea: Flag en commits → tarea automatica

Usar tags en mensajes de commit para generar tareas en RepoMind:

```bash
git commit -m "Refactor auth flow [test] [bug]"
```

Tags propuestos:
- `[test]` → crea tarea "Probar: Refactor auth flow" en columna "To-Do"
- `[bug]` → crea tarea "Bug: Refactor auth flow" en columna "Brainstorming"
- `[review]` → crea tarea "Revisar: Refactor auth flow"

Implementacion via **git hook post-commit**:

```bash
#!/bin/bash
MSG=$(git log -1 --pretty=%B)

if echo "$MSG" | grep -q "\[test\]"; then
    CLEAN=$(echo "$MSG" | sed 's/\[test\]//g;s/\[bug\]//g;s/\[review\]//g' | xargs)
    REPO=$(basename $(git rev-parse --show-toplevel))
    open "repomind://add-task?content=Probar:+${CLEAN// /+}&repo=$REPO&column=To-Do"
fi

if echo "$MSG" | grep -q "\[bug\]"; then
    CLEAN=$(echo "$MSG" | sed 's/\[test\]//g;s/\[bug\]//g;s/\[review\]//g' | xargs)
    REPO=$(basename $(git rev-parse --show-toplevel))
    open "repomind://add-task?content=Bug:+${CLEAN// /+}&repo=$REPO&column=Brainstorming"
fi
```

Distribucion: incluir script instalable desde Settings de la app o como comando CLI.

### Idea: Claude Code hooks

Usar el sistema de hooks de Claude Code para crear tareas automaticamente al terminar trabajo:

```json
// .claude/hooks.json
{
  "post_tool_use": [
    {
      "matcher": { "tool_name": "bash", "output_contains": "Build Succeeded" },
      "command": "open 'repomind://add-task?content=Build+OK:+probar+cambios&repo=RepoMind&column=To-Do'"
    }
  ]
}
```

Casos de uso:
- Tras build exitoso → tarea de testing
- Tras crear archivo nuevo → tarea de review
- Tras fix de bug → tarea de verificacion

### Idea: Parseo de TODOs en codigo

Escanear archivos Swift buscando `// TODO:` y crear tareas:

```bash
grep -rn "// TODO:" --include="*.swift" . | while read line; do
    FILE=$(echo "$line" | cut -d: -f1)
    TODO=$(echo "$line" | sed 's/.*\/\/ TODO: //')
    REPO=$(basename $(git rev-parse --show-toplevel))
    open "repomind://add-task?content=${TODO// /+}&repo=$REPO&column=Brainstorming"
done
```

Podria ejecutarse como GitHub Action o como comando local.

### Idea: GitHub Actions

Workflow que crea tareas en RepoMind al detectar eventos:

```yaml
# .github/workflows/repomind.yml
on:
  push:
    branches: [main]

jobs:
  notify:
    runs-on: macos-latest
    steps:
      - name: Create test task
        run: |
          # Requiere que el Mac runner tenga RepoMind instalado
          # Alternativa: webhook a un servidor intermedio
          echo "Pendiente: definir mecanismo de comunicacion remota"
```

**Nota:** Esto requiere un componente servidor o push notifications. Evaluar si merece la complejidad.

## 2. Nuevas funcionalidades

### Sync con GitHub Issues

- Sincronizar issues del repo como tareas en el tablero Kanban
- Mapeo: labels de GitHub → columnas Kanban
- Bidireccional: mover tarea en Kanban → actualizar issue en GitHub
- Complejidad alta, evaluar bien el scope

### Widgets (iOS/macOS)

- Widget pequeno: contador de tareas pendientes por repo
- Widget mediano: lista de tareas de la columna "To-Do"
- Widget grande: vista mini del tablero Kanban
- Usar WidgetKit + AppIntents para interactividad

### Push Notifications

- Notificar cuando un collaborador crea/mueve una tarea (requiere backend)
- Recordatorios locales para tareas con fecha limite (no requiere backend)
- Empezar por recordatorios locales, mucho mas simple

### Busqueda global de tareas

- Buscar tareas across todos los repos
- Filtros: por columna, por fecha, por contenido
- Spotlight integration con CSSearchableItem

### Atajos de Siri / Shortcuts

- "Crear tarea en RepoMind" via Siri
- AppIntents framework para integracion nativa
- Complementa perfectamente el URL scheme
